Chrome/Edge extension that keeps employees focused on order fulfillment in Walmart Seller Center.

**What employees see:** the homepage without the GMV graph or the Current Balance tile, dollar amounts shown as `$•••`, and no Payments or Analytics.

## Download

| Computer | File | Notes |
|---|---|---|
| Windows | `SellerCenterFulfillmentMode-Setup-….exe` | If Windows shows "Windows protected your PC", click **More info → Run anyway**. The installer copies the folder's path for you and opens Chrome's extensions page. |
| Mac | `SellerCenterFulfillmentMode-….dmg` | Open it and follow **INSTALL - read me first.txt**. |
| Any | `walmart-fulfillment-mode-….zip` | Manual install. See SETUP.txt inside. |

## Finishing in Chrome (one time per computer)

1. Go to `chrome://extensions` and turn on **Developer mode**. Leave it on.
2. Click **Load unpacked** and pick the installed folder.

**Updating:** install the new version, then click the reload arrow on the extension in `chrome://extensions`.

Install it only on employee computers. It's a guardrail, not a lock: someone could turn it off, or use another browser or the Walmart Seller phone app.
